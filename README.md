# 🚚 Shipping Route Dashboard

A Streamlit-based interactive dashboard for analyzing factory-to-customer shipping performance. This project helps identify efficient shipping routes, delivery delays, regional bottlenecks, and overall logistics performance using real-world shipment data from Nassau Candy Distributor.

---

## 📌 Project Overview

Efficient shipping is essential for reducing operational costs and improving customer satisfaction. This dashboard analyzes shipping data to provide actionable insights into delivery performance across different regions, states, and shipping modes.

The dashboard enables users to monitor shipping efficiency through interactive visualizations and performance metrics.

---

## ✨ Features

- 📊 Interactive KPI Dashboard
- 🚚 Shipping Lead Time Analysis

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/AishAftab098/ShippingRouteDashboard.git
```

Move into the project directory:

```bash
cd ShippingRouteDashboard
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the Streamlit application:

```bash
streamlit run app.py
```
